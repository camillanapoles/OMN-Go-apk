# OMN-Go fork — 26.11.36

<!-- Um bullet por mudança, o que mudou da versão anterior para esta, em linguagem da pessoa usuária. Regras no ADR 0031. -->

• A partir desta versão, cada release do fork sai somente quando uma especificação está completamente concluída, com todas as tarefas provadas.
• As notas de cada release passam a trazer um resumo claro do que muda para quem usa o aplicativo, da versão anterior para esta.
• A pessoa responsável pela release dispara uma única ação no GitHub com o número da issue concluída, e o sistema confere todos os critérios antes de publicar.
• Se qualquer critério falhar, nada é publicado, e a mensagem de erro mostra exatamente o que falta concluir.
• O build de teste por pull request continua existindo para validar o código, mas ele não publica mais release nenhuma.
